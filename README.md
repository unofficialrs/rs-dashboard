# rs-dashboard

**RS Dashboard** is a small desktop window for Windows 11 / macOS. It shows live Rocket Scooter market data.

**Features**
- Live charts of RESILIENCE and liquidity data for ES, NQ and RTY
- A strip of key numbers
- An Arb price basis, including a delayed mode that scales by the ES/NQ futures price from Yahoo, with a contract picker
- A sign-in that securely saves the login in the Windows credential store or Keychain on macOS
- A Settings dialog and a compact title bar that can be collapsed
